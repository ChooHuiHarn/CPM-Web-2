# Cureer

A static career guidance website that helps users explore careers through a quiz and a jobs/career info page.

## Stack

- Pure HTML, CSS, and JavaScript — no build step, no framework
- Python 3.11 HTTP server for local development

## Pages

- `index.html` — Landing page with hero section
- `quiz.html` — Career quiz
- `job.html` — Career/job information page

## How to run

The **Start application** workflow runs:

```
python3 -m http.server 5000
```

The site is served on port 5000.
