# Cureer

A static career-quiz web app that helps users (especially teenagers) discover suitable career paths using a RIASEC-based personality assessment.

## Stack

- Pure HTML / CSS / JavaScript — no build step, no framework
- Served with [`serve`](https://github.com/vercel/serve) (global npm package)

## Pages

| File | Route | Description |
|---|---|---|
| `index.html` | `/` | Landing page with hero, quiz banner, careers carousel, FAQ, contact form |
| `quiz.html` | `/quiz.html` | 7-question RIASEC career quiz |
| `jobbig.html` | `/jobbig.html` | Browse jobs / careers |
| `job.html` | `/job.html` | Individual job detail page |

## Running locally

```bash
serve -l 5000 .
```

The Replit workflow **Start application** runs this command automatically.
