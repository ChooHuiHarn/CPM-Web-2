# Cureer

A static career guidance website that helps teenagers and young adults discover suitable career paths using the RIASEC personality model.

## Pages
- **index.html** — Home page with hero, quiz CTA, careers carousel, FAQ, and contact form
- **quiz.html** — RIASEC-based 7-question career assessment quiz
- **jobbig.html** — Jobs listing page (detailed view)
- **job.html** — Individual job detail page

## Stack
- Pure HTML, CSS, JavaScript — no build step required
- Served with `serve` (npm package) on port 5000

## How to run
```
serve -l 5000 .
```
The "Start application" workflow handles this automatically.
